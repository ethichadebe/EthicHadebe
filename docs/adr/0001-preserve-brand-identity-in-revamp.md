# Preserve brand identity in the visual revamp

The site is getting a modernization pass (layout, typography rhythm, animation) inspired by external references (stevenbartlett.com, daofor.design, nivora.framer.website, arocksworld.com, evanfasquelle.com). We decided the glitch-text alternating "Ethic"/"Hadebe" hero effect, the `Moul` display font, and the black + maroon (`#730206`) accent color all stay as-is. This is a restyle/revamp of the existing brand, not a rebrand — prototype variants should build outward from these anchors rather than replace them.
